The short version

Problem, work, answer

The whole project in three cards.

01 / problem

One big question

"How are our products doing in the UAE, and what can we improve?" It is too big to answer at once, so I split it into four smaller questions.

02 / work

Clean, filter, compare

I fixed rating columns stored as text, kept only UAE products, converted Gulf prices to AED and compared only products sold in all three countries.

03 / answer

Fix sofas, use the price

Sofas have the lowest rating (3.93). The UAE is about 15% cheaper than Saudi Arabia. "Top Seller" means popular, not better rated.

DATAPublic data: the IKEA Global Product Catalog and Price 2026 dataset on Kaggle. It is a snapshot of the online catalogue with ratings and prices, not IKEA's internal sales data.

Recommendations

What I would tell the manager

Three actions, each backed by a finding above.

Read the sofa reviews to find the main problem: comfort, quality or delivery.

Use the price advantage in marketing. The UAE is about 15% cheaper than Saudi Arabia.

Don't read "Top Seller" as "best quality". The badge shows popularity, not higher satisfaction.

LIMITSThe data has no sales numbers, so review count is only a sign of popularity. It is one snapshot in time, so there are no trends, and 131,960 rows in the full data have no rating.

Process

How I did it

Python (pandas, NumPy, matplotlib) in a Jupyter notebook.

step_01

Explore

Checked rows, columns and data types. No empty cells, but the rating columns were stored as text.

step_02

Clean

Replaced the word "none" with NaN, not 0, so products with no rating don't pull the average down.

step_03

Filter & compare

Kept the 9,242 UAE products. For prices, converted SAR and QAR to AED and used pivot_table + dropna to keep only products sold in all 3 countries.

step_04

Analyse & show

Used groupby and agg by category and badge, then one simple bar chart per finding.
